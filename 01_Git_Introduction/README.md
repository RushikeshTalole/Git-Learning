# Git Introduction

## What is Git?

Git is a **Distributed Version Control System (DVCS)** used to track changes in files and manage source code.

It helps developers:

- Track changes in code.
- Maintain different versions of a project.
- Work safely without losing previous changes.
- Collaborate with other developers.

---

## Why Do We Use Git?

Without Git, it becomes difficult to manage multiple versions of a project.

Git helps us to:

- Track who changed what and when.
- Restore previous versions.
- Create separate branches for new features.
- Work with other developers.
- Maintain a complete history of changes.

---

## Git vs GitHub

| Git | GitHub |
|---|---|
| Version Control System | Cloud-based platform |
| Runs on your computer | Runs on the internet |
| Tracks project changes | Hosts Git repositories |
| Works locally | Used for collaboration |

---

## Important Git Concepts

- **Repository** → Project managed by Git.
- **Working Directory** → Files where we currently work.
- **Staging Area** → Area where changes are prepared for commit.
- **Commit** → Saved snapshot of changes.
- **Branch** → Separate line of development.
- **Remote Repository** → Repository hosted on a remote server such as GitHub.

---

## Interview Questions

### 1. What is Git?

**Answer:**

> Git is a distributed version control system used to track changes in source code and manage different versions of a project.

### 2. What is GitHub?

**Answer:**

> GitHub is a cloud-based platform used to host Git repositories and collaborate with other developers.

### 3. Is Git and GitHub the same?

**Answer:**

> No. Git is a version control system, while GitHub is a platform used to host and collaborate on Git repositories.

---

## Key Points

- Git is a **Version Control System**.
- Git works locally on our computer.
- Git tracks changes in files.
- Git maintains project history.
- GitHub is used to host Git repositories online.
