# Git Installation

## What is Git Installation?

Git installation means installing Git on our computer so that we can use Git commands and manage repositories locally.

---

## How to Check if Git is Installed?

Open Git Bash or Command Prompt and run:

git --version

Example output:

git version 2.x.x

If a Git version is displayed, Git is successfully installed.

---

## Git Installation on Windows

### Steps

1. Download Git for Windows from the official Git website.
2. Run the Git installer.
3. Follow the installation wizard.
4. Keep the default options unless you have a specific requirement.
5. Complete the installation.
6. Open Git Bash.
7. Verify the installation using:

git --version

---

## Git Bash

Git Bash is a command-line environment for Windows that allows us to use Git commands.

Example:

git status
git add
git commit
git log

---

## Git vs Git Bash

| Git | Git Bash |
|---|---|
| Version Control System | Command-line environment |
| Tracks changes | Allows us to run Git commands |
| Provides Git functionality | Provides a terminal to use Git |

## Interview Questions

### 1. How do you check whether Git is installed?

Answer:

We can use the git --version command to check whether Git is installed on the system.

### 2. What is Git Bash?

Answer:

Git Bash is a command-line environment for Windows that allows us to use Git commands.

### 3. Where does Git work?

Answer:

Git works locally on our computer and tracks changes in our projects.

---

## Key Points

- Git must be installed before using Git commands.
- git --version checks the installed Git version.
- Git Bash provides a terminal for Git commands on Windows.
- Git works locally on our computer.
