# Git Pull

## What is Git Pull?

`git pull` is a Git command used to download the latest changes from a remote repository and update the local repository.

---

## Why Do We Use Git Pull?

We use `git pull` to get the latest changes from GitHub into our local repository.

---

## Syntax

git pull

---

## Example

Suppose someone makes changes to the remote repository on GitHub.

To get those latest changes into our local repository, we use:

git pull

Git downloads the latest changes and updates the local repository.

---

## Basic Flow

    Remote Repository
          ↓
       git pull
          ↓
    Local Repository

---

## Difference Between Git Push and Git Pull

### git push

`git push` sends local commits to the remote repository.

### git pull

`git pull` gets the latest changes from the remote repository to the local repository.

---

## Example

To upload local changes:

git push

To get the latest remote changes:

git pull

---

## Important Point

`git pull` is used to get the latest changes from the remote repository.

It helps keep the local repository up to date.

---

## Key Points

- `git pull` gets changes from a remote repository.
- It updates the local repository.
- It is commonly used with GitHub.

- `git pull` gets changes from the remote repository.
